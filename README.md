## ДЗ 1

Инструкции по установке и запуску находятся в [hw1/README.md](hw1/README.md).
Команды выполняются из папки `hw1`. Версии библиотек закреплены в `uv.lock`,
модель и параметры задаются в `params.yaml`.

В репозитории находятся исходный код, конфигурация, проверки, отчёт и
результаты измерений. Веса моделей скачиваются при первом запуске.

Тема будущего проекта: [классификация обращений на GitHub](hw1/docs/dataset_plan.md).
Предложение подготовлено; согласование преподавателя ожидается.

## ДЗ 2

Запуск из папки `hw2`: `make install`, `make inspect`, `make test`, `make check`.
В [отчёте](hw2/docs/anatomy.md) приведены реальные измерения, условия и исправления.
[Сводная таблица Excel](hw2/docs/anatomy-worksheet.xlsx) содержит оба расчёта LoRA и контрольные формулы.
