# ДЗ 2. Анатомия языковой модели

Губин Виталий Андреевич, ИУ6-74Б.

Работа продолжает ДЗ 1: та же базовая модель, компьютер и версии основных
библиотек. Здесь исследуются параметры, внутренние активации и память
при инференсе, полном обучении и обучении адаптеров LoRA.

Все команды выполняются из папки `hw2` репозитория курса.

```bash
cd hw2
make install
make inspect
make test
make check
```

Требуются Python 3.12, `uv` и `make`. `uv sync --locked` создаёт отдельное
окружение и устанавливает версии из `uv.lock`. Инструкция установки `uv`:
https://docs.astral.sh/uv/getting-started/installation/

В проверенном запуске использованы Apple M3 Pro, macOS 15.7.9 и `mps`.
На другом компьютере поменяйте `model.device` в `params.yaml` на `auto`,
`cpu` или `cuda`; метод измерения памяти выбирается по устройству.
Первый запуск скачивает веса. Затем можно выполнять команды с
`HF_HUB_OFFLINE=1` перед `make`. Платные сервисы не нужны.

## Результаты

- Уникальных параметров: **596 049 920**. Общие веса входа и выхода учтены один раз.
- LoRA r=8 на q/v: **1 146 880** параметров.
- LoRA r=16 на семи типах проекций: **10 092 544** параметра.
- Пики памяти MPS: **1512,8 / 7106,6 / 3239,8 МиБ**
  для инференса / полного обучения / LoRA.
- Исходная проверка преподавателя: **7 из 7**.
- Дополнительные проверки: **6 из 6**.

Условия: bf16 для базы, fp32 для адаптеров, последовательность 256 токенов,
один пример, один шаг AdamW, кэш ключей и значений выключен. Каждый режим
повторён трижды в новых процессах, выбран максимум пиков.
