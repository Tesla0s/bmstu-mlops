Сохраняется тема из ДЗ 1: классификация обращений на GitHub.
В этой работе нет обучения модели, обращения к платным сервисам или записи видео.

## Автоматические проверки

Команда `make verify` выполняет пересчёт стадий, 13 дополнительных тестов,
проверку Python-кода и все восемь разделов исходного `tests/check.sh`.
Файл преподавателя не изменён; его SHA-256:

~~~text
5cb5aa3c97cb7e397edf3ef34ae4a9b85ca7bf928e217c213b03b0d8f3d43838
~~~

Дополнительные тесты проверяют точность поиска близких текстов относительно
полного перебора, границу порога, строгую схему и номер ошибочной строки,
очистку контактов без повреждения кода и значимых URL, неразрывность семейств
и отклонение набора с одним классом.

Проверка отсутствия пересечений основана на идентификаторах, нормализованных
текстах, установленных группах и лексическом сходстве с порогом Жаккара 0,85.
Она не доказывает отсутствие всех смысловых перефраз или ошибок исходных меток.
Проверено содержание 120 обращений с помощью ИИ; независимая человеческая
проверка всей разметки не выполнялась.

Результат финального запуска: все восемь разделов проверки преподавателя,
13 дополнительных тестов и проверка оформления прошли.
[Сохранённый вывод команды](../reports/verification.txt).

## Восстановление в отдельной копии

Проверка выполнена в новом клоне Git, с новым окружением Python 3.12.14
и изначально пустым кэшем DVC. Через `dvc pull source.dvc` восстановлен
только зафиксированный исходник; готовых raw/clean/train/val/test в копии не было.
Затем `dvc repro --force` заново выполнил все стадии.

SHA-256 всех пяти полученных JSONL совпали с [зафиксированными значениями](../reports/versions.json).
Повторный `make verify` прошёл; после проверки Git не содержит изменений.
Воспроизведение не обращалось к GitHub API и не получало новые тексты из интернета.
Установка окружения использует версии из `uv.lock`.

Отдельно проверено восстановление v1 и v2 через `dvc pull` с ещё одним пустым
кэшем: обе версии получены из локального хранилища, без пересчёта.
Все контрольные суммы совпали; `dvc status` не обнаружил изменений.

[Машиночитаемый протокол](../reports/reproduction.json) содержит команды,
длительности, проверенный коммит и контрольные суммы. Последующие изменения
инструкции сохранения данных не меняют обработку и содержимое датасета.

[Сохранённая разница метрик DVC](../reports/metrics_diff.md):
число очищенных записей 1437 → 1878, прирост 441.
