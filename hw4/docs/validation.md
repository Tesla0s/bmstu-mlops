## Что запускалось

make verify: воспроизведение через DVC, 14 дополнительных тестов,
проверка ошибок и оформления Python, неизменённый make check и полный
аудит сохранённых файлов. Все команды завершились успешно.

[Полный вывод проверки](../reports/verification.txt).
[Первый запуск исходной заготовки](../reports/baseline_check.txt) содержит шесть
красных разделов и показывает исходные симптомы.
[Проверка каждого готового примера](../reports/artifact_audit.json)
содержит контрольные суммы результатов и отпечаток проверки преподавателя.

При отрицательном испытании предел был временно уменьшен до 232 только
в отдельном процессе. Диагностический отчёт записан в рабочей папке вне Git;
основные параметры, метрики и файлы токенов не заменялись.
Результат: 657 обрезанных train, 162 val, код завершения 1, новых тензоров нет.
[Машиночитаемый результат](../reports/threshold_failure.json).

## Воспроизведение

Проверка выполнена в новом Git-клоне, с новым окружением Python 3.12.14,
пустым кэшем DVC и новым кэшем Hugging Face. Скачаны только файлы токенизатора;
версия сверена с закреплённым коммитом. Весов модели в новом кэше нет.

Через dvc pull inputs.dvc восстановлены только исходные train/val.
Готовых файлов токенов в клоне не было. Команда dvc repro --force заново
выполнила обработку; следующий make verify прошёл целиком.

Побайтово совпали все восемь проверенных файлов: два входных JSONL,
два файла токенов, metrics/tokenize.json, docs/tokenize_report.md,
reports/artifact_audit.json и dvc.lock. После проверки Git чистый.
DVC подтвердил синхронизацию кэша и локального хранилища.

[Протокол воспроизведения](../reports/reproduction.json) содержит проверенный
коммит, команды, длительности и SHA-256. Последующие изменения документации
не меняют обработку и содержимое подготовленных файлов.

## Границы этой работы

Обучение модели, проверка её точности и видео в эту содержательную проверку
не входят. ДЗ 4 готовит и проверяет вход для будущего обучения.
Проверка токенов не доказывает правильность всех исходных меток GitHub:
ограничения исходных данных описаны в паспорте ДЗ 3.

Использованы официальные описания
[шаблонов диалога Transformers](https://huggingface.co/docs/transformers/v4.57.1/chat_templating)
и [шаблона закреплённой версии Qwen3](https://huggingface.co/Qwen/Qwen3-0.6B/blob/c1899de289a04d12100db370d81485cdf75e47ca/tokenizer_config.json).
Никакие веса модели на этом этапе не загружались.
