## Запуск

Нужны Git, Python 3.12 и uv. Все команды выполняются из папки hw4:

~~~bash
make install
make prepare
make verify
~~~

make prepare копирует проверенные файлы из соседней папки hw3 и сверяет SHA-256.
Если данных ДЗ 3 ещё нет, сначала восстановите hw3-v2 из его локального
DVC-хранилища по инструкции ДЗ 3. Часть test в ДЗ 4 не используется.

Другой способ — восстановить уже подготовленные входы и результаты из
хранилища ДЗ 4. При переносе проекта укажите реальный путь локально:

~~~bash
uv run dvc remote modify --local local url /полный/путь/к/dvc_remote
make pull-data
make verify
~~~

Git содержит код, конфигурацию, указатели DVC и отчёты. Одного клонирования
репозитория для получения данных недостаточно: локальное хранилище не публикуется.
Файлы train/val учтены в inputs.dvc, выход data/tokenized — в стадии tokenize.
Команда make push-data сохраняет оба входа и результаты в настроенном хранилище.

При первом запуске скачиваются только файлы токенизатора, без весов модели.
Ревизия закреплена в params.yaml; версии библиотек — в uv.lock.
Кэш токенизатора находится в .cache/huggingface. Для уже заполненного кэша можно
использовать HF_HUB_OFFLINE=1.

## Команды

| Команда | Что делает |
|---|---|
| make prepare | Проверить и скопировать собственные train/val из ДЗ 3 |
| make tokenize | Принудительно обработать оба входа и создать метрики и отчёт |
| make repro | Пересчитать стадию через DVC, если данные, код или параметры изменились |
| make check | Девять неизменённых проверок преподавателя |
| make test | 14 дополнительных тестов границ маски, обрезки, схемы и батчей |
| make audit | Сверить каждый сохранённый пример, ответ, конец реплики и все батчи |
| make verify | DVC, тесты, проверка Python-кода, проверка преподавателя и аудит файлов |

Исходный tests/check.sh сохранён побайтово. Его отпечаток: f2002c8c9519.

## Формат результата и использование дальше

data/tokenized/train.pt и val.pt содержат словарь examples и сведения о
токенизаторе, входном файле, пределе длины и стороне дополнения.
В каждой записи: id, input_ids, attention_mask, labels — списки целых чисел
переменной длины. Файлы читаются через torch.load с weights_only=True.
Тензоры батча создаёт DynamicPaddingCollator из src/collate.py.

Для обучения и получения ответа используется build_chat_text из src/prompt.py.
При add_generation_prompt=True функция принимает как полный размеченный пример,
так и диалог system/user без готового ответа. Шаблон вручную не дублируется.

Грубый прогноз трёх эпох по формуле курса: 8,295 ч по скорости генерации,
16,590–24,885 ч при допущении замедления в 2–3 раза.
Это расчёт по измерению Mac из ДЗ 1, не замер обучения и не оценка скорости Kaggle.
Выбор оборудования и реальная проверка времени относятся к ДЗ 5.
