## Подготовка

Нужны Python 3.12, uv, Docker и Docker Compose. На macOS использован Colima.
Сначала восстановите входы ДЗ 4 через его DVC-процесс. В этом каталоге
`uv sync --frozen` устанавливает отдельное окружение. Кэш Hugging Face можно
переиспользовать через `HF_HOME`; первая загрузка базы требует доступа к сети.

Точные правила выбора и допуска закреплены до измерений:
[протокол](docs/evaluation-plan.md). Данные проверки и исходные JSONL
версионируются через DVC; [происхождение данных](reports/data-lineage.json).
Индекс содержит все 1315 вопросов train, хотя в коротком поиске используются 32.

## Выполнение

```bash
uv sync --frozen
make check-eval
make up
make sweep
make report
make candidate
make baseline-init
make evaluate
make eval
make check-negative
# Только если make eval вернул PASS:
make promote
make check-storage
make check-all
```

При отказе `make eval` возвращает ненулевой код; `make promote` не запускают.
Отказ считается допустимым результатом задания. Baseline самостоятельно не меняется.

MLflow доступен локально: http://127.0.0.1:5006.
`make down` останавливает сервисы, сохраняя именованные тома.
Не используйте `docker compose down -v`: эта отдельная команда удаляет данные.
Для повторения не нужно переобучать модели, если исходный код, конфигурация и данные
не менялись. `make check` проверяет готовые шесть запусков и candidate.
